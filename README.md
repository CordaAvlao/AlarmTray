🛎️ AlarmTray (BeepScheduler) V3.0

AlarmTray is a modern, lightweight alarm and beep scheduler for Windows. It runs quietly in the background and stays accessible from the system tray next to the clock.

✨ **What's New in Version 3.0**
- **New Audio Engine (NAudio)**: Fully rewritten audio system using NAudio and WasapiOut.
- **Full MP3 & WAV Support**: Play any audio file reliably.
- **Precise Volume Control**: Software volume slider (0-100%) now fully functional.
- **Two Distribution Modes**: Choose between a standalone "all-in-one" EXE or a super-lightweight version.
- **Next Alarm Tooltip**: Hover over the tray icon to see the next scheduled alarm.
- **Light/Dark Themes**: Modern interface that respects your preference.

🖥️ **How It Works**
1. Launch `BeepScheduler.exe`.
2. A bell icon appears in the system tray.
3. **Right-click** → **Settings** to configure your alarms.
4. **Left-click** → **Stop** the alarm when it rings.

📥 **Download / Installation**
Latest releases are available here: [Releases](https://github.com/CordaAvlao/AlarmTray/releases)

### 📦 Which version to choose?
- **BeepScheduler.exe (Standalone)**: ~160 MB. Includes the entire .NET runtime. Works anywhere without installation.
- **BeepScheduler_Light.exe (Lightweight)**: < 1 MB. Requires the [.NET 7.0 Desktop Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/7.0) to be installed on your PC.

🛎️ AlarmTray (BeepScheduler) V3.0 (Français)

AlarmTray est un petit utilitaire Windows léger qui permet de programmer facilement des alarmes quotidiennes, avec un bip système ou un fichier MP3/WAV, directement depuis la zone de notification.

✨ **Nouveautés de la Version 3.0**
- **Nouveau Moteur Audio (NAudio)** : Système audio entièrement réécrit pour une compatibilité maximale.
- **Support MP3 et WAV** : Jouez n'importe quel fichier audio sans erreur.
- **Contrôle du Volume Réel** : La barre de volume (0-100%) fonctionne désormais parfaitement pour toutes les sources sonores.
- **Deux Modes de Distribution** : Choisissez entre une version "tout-en-un" ou une version "poids plume".

🖥️ **Fonctionnement**
1. Lancez `BeepScheduler.exe`.
2. Une icône de cloche apparaît près de l'horloge.
3. **Clic droit** → **Paramètres** pour configurer vos alarmes.
4. **Clic gauche** → **Arrêt** de l'alarme lorsqu'elle sonne.

📥 **Téléchargement**
Les fichiers sont disponibles dans la section [Releases](https://github.com/CordaAvlao/AlarmTray/releases).

### 📦 Quelle version choisir ?
- **BeepScheduler.exe (Autonome)** : ~160 Mo. Contient tout le nécessaire. Fonctionne partout.
- **BeepScheduler_Light.exe (Léger)** : < 1 Mo. Nécessite l'installation du [Runtime .NET 7.0](https://dotnet.microsoft.com/fr-fr/download/dotnet/7.0).
