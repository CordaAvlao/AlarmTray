🛎️ AlarmTray (BeepScheduler) V2.5

AlarmTray is a modern, lightweight alarm and beep scheduler for Windows. It runs quietly in the background and stays accessible from the system tray next to the clock.

✨ **What's New in Version 2.5**
- **New Audio Engine (NAudio)**: Fully rewritten audio system using NAudio and WasapiOut for maximum reliability.
- **Full MP3 & WAV Support**: Play any audio file (radio, music, alarm sounds) without errors.
- **Precise Volume Control**: Dedicated software volume slider (0-100%) now fully functional.
- **Two Distribution Modes**: Choose between a standalone "all-in-one" EXE or a super-lightweight version.

🚀 **Core Features**
- **System Tray Integration**: Stays discreetly in your taskbar.
- **Visual Shutdown Alerts**: Configurable automatic Windows shutdown with 5-minute and 1-minute countdown warnings.
- **Next Alarm Tooltip**: Just hover over the tray icon to see your next appointment.
- **Smart Scheduling**: Set alarms for specific days of the week with easy activation/deactivation.
- **Light & Dark Themes**: Modern UI that respects your Windows system preferences.
- **Integrated Sounds**: High-quality built-in sounds (Casio Chime, Siren, Digital Alarm, etc.).
- **Import/Export**: Move your settings easily between computers via JSON files.

🖥️ **How It Works**
1. Launch `BeepScheduler.exe`.
2. A bell icon appears in the system tray.
3. **Right-click** → **Settings** to configure your schedule and sounds.
4. **Left-click** → **Stop** the alarm instantly when it rings.

🛎️ AlarmTray (BeepScheduler) V2.5 (Français)

🚀 **Fonctionnalités Principales**
- **Icône Système** : Travaillez sans distraction, l'app reste discrète près de l'horloge.
- **Extinction Automatique** : Programmez l'arrêt du PC avec des alertes de compte à rebours (5 min / 1 min).
